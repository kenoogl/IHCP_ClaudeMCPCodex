## 💡 精度向上の理由

### 1. 収束判定の厳密性

**Phase 1-E（適応的収束判定）**:
- デフォルトtol: 1e-6
- 適応的に緩和: **1e-5**（10倍緩い）⚠️
- 目的: 反復回数削減による高速化
- 代償: **精度の犠牲**

**体積積分形式**:
- デフォルトtol: **1e-6**（厳密）✅
- 適応的緩和なし
- 反復回数: 10-12回（Phase 1-Eの1/40）
- 結果: **高速かつ高精度** 🏆

**結論**: Phase 1-Eは適応的tolで精度を犠牲にして高速化
体積積分形式は**行列の条件数改善により、精度を維持しつつ高速化**

### 2. 反復回数と丸め誤差

**反復回数の比較**:
- Phase 1-E: 平均400-600回/ステップ
- 体積積分形式: 平均10-12回/ステップ

**丸め誤差の蓄積**:
- 反復回数が多いほど丸め誤差が蓄積
- Phase 1-Eは400-600回の反復で誤差が蓄積 ⚠️
- 体積積分形式は10-12回の反復で誤差蓄積が少ない ✅

**結論**: 少ない反復回数 → 高い数値安定性

### 3. 対角優位性と数値安定性

**体積積分形式の特徴**:
1. **スケーリングの統一**: 全ての項が体積スケール（dx×dy×dz）
2. **時間項の寄与**: `ρ * cp * dx * dy * dz / dt`が対角項を強化
3. **対角優位性**: 対角項 >> 非対角項
4. **前処理の効果**: Gauss-Seidel法が最大限の効果を発揮

**結果**:
- 行列の条件数が改善 → 数値安定性向上 ✅
- 収束が速い → 丸め誤差の蓄積が少ない ✅
- 前処理が効果的 → 収束が加速 ✅

### 4. 物理的妥当性

**体積積分形式の利点**:
- エネルギー保存則を厳密に表現
- 熱伝導項・対流項・時間項が物理的に一貫
- 離散化誤差が小さい

**Phase 1-Eの問題**:
- 適応的tolにより収束が不十分
- エネルギー保存が厳密でない可能性
- 表面温度の空間分布が一様（標準偏差0）← 非物理的
