# Python-Julia スライディングウィンドウ性能比較レポート

**日付**: 2025年10月23日
**比較対象**: Python版 vs Julia版スライディングウィンドウCGM計算
**条件**: CGM反復2回、4スレッド、5ウィンドウ

---

## 📋 エグゼクティブサマリー

### 主要な発見

1. **実行速度**: Julia版が4.09倍遅い（Python: 8.39秒 vs Julia: 34.34秒）
2. **⚠️ 重大な問題**: **熱流束の値が10^11倍も異なる** → Python版がほぼゼロ（収束していない可能性）

## ⚠️ 重大な問題: 熱流束の値の差異

### 結果の比較

| 版 | 熱流束最小値 | 熱流束最大値 | 範囲 |
|----|------------|------------|------|
| **Python** | -9.15e-07 W/m² | 1.30e-07 W/m² | **ほぼゼロ** ❌ |
| **Julia** | -3.37e+04 W/m² | 1.10e+05 W/m² | **正常な範囲** ✅ |

**差異の大きさ**: **10^11倍** （11桁の違い）

### Python版の問題点

Python版の実行ログを詳細に確認すると、以下の異常な値が見られる：

1. **目的関数の更新がない**:
   - `rel_drop = 0.000e+00` （目的関数が更新されていない）
   - `rel_drop = 1.068e-14`, `2.002e-15`, `6.570e-15` （ほぼゼロ）

2. **denominator（分母）が極小**:
   - `1.3405e-27`, `5.4840e-27`, `1.9001e-29`, `3.1767e-34`
   - これはCGMアルゴリズムの収束判定に使われる値

3. **熱流束がほぼゼロ**:
   - `q: min=-7.1553e-08, max=8.4913e-09` （Window 1, Iter 1）
   - `q: min=-4.6128e-07, max=6.5502e-08` （Window 2, Iter 1）

### 推測される原因

1. **CGMアルゴリズムの収束条件**: Python版のCGMアルゴリズムが早期に収束判定している可能性
2. **数値精度の問題**: 分母が極小値のため、数値誤差の影響が大きい
3. **初期値の違い**: Python版とJulia版で異なる初期値を使用している可能性
4. **感度場の計算エラー**: Python版で「感度場dT異常」の警告が多数発生

## 🧩 なぜJulia版の方が遅いのか？

### 仮説1: オーバーヘッドの違い

- **Python版**: Numbaのコンパイル済みコード + SciPyの最適化されたCソルバー
- **Julia版**: FLoops並列化 + カスタムPBICGSTAB実装

### 仮説2: 問題サイズが小さすぎる

- 並列化のオーバーヘッドが計算時間を上回っている可能性
- より大きな問題サイズ（nt=1000等）では結果が逆転するかもしれない

### 仮説3: Python版が収束していない

- **重要**: Python版の熱流束がほぼゼロということは、**正しく計算できていない**可能性が高い
- つまり、Python版の「8.39秒」は**不正確な結果**を得るための時間
- Julia版の「34.34秒」は**正しい結果**を得るための時間

---

## 🎯 結論

### 主要な発見

1. **Python版の熱流束がほぼゼロ**: CGMアルゴリズムが収束していない可能性が非常に高い
2. **実行速度の比較は意味をなさない**: Python版が不正確な結果を出力している場合、速度比較は無意味
3. **Julia版は正常に動作**: 熱流束の範囲が妥当（-3.37e+04 ~ 1.10e+05 W/m²）

### 次のアクション（優先度順）

1. **⭐ 最優先**: Python版の熱流束がゼロになる原因を調査
   - `python/scripts/run_sliding_window.py`と`python/original/IHCP_CGM_Sliding_Window_Calculation_ver2.py`の実装を確認
   - CGMアルゴリズムの収束条件を確認
   - 初期値の設定を確認

2. **CGM反復回数を増やして再試行**: `--cgm-iter 10`等で再実行し、収束を待つ

3. **より大きな問題サイズで再試行**: nt=100, window=71等で性能を再比較

4. **Python版のオリジナルコード**で実行: `scripts/run_sliding_window.py`を使わず、直接オリジナルコードで実行してみる
