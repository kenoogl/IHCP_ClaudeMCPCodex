## 📋 調査経緯

### Phase 1: ソース項係数の修正（効果なし）

**発見**:
随伴問題のソース項係数が異なっていた。

**修正前** (1276行):
```python
if k_ijk == 0:
    rhs += 2 * (T_cal[i, j] - Y_obs[i, j]) * dx * dy
```
実効係数 = **2.0**

**修正後** (1275-1276行):
```python
if k_ijk == 0:
    residual_scale = 0.5  # Julia版と同じ（adjoint_residual_scale）
    rhs += 2 * residual_scale * (T_cal[i, j] - Y_obs[i, j]) * dx * dy
```
実効係数 = 2.0 × 0.5 = **1.0**（Julia版デフォルトと一致）

**結果**:
- ✅ Julia版との係数は一致
- ❌ **gradとqの値は改善せず、依然としてe-09, e-06オーダー**

**結論**: ソース項係数は問題の根本原因ではない

## 🔍 疑わしい箇所

### 🔴 最重要: 随伴方程式のRHS符号

**Julia版** (AdjointSolver.jl:161-162):
```julia
a_p_0 = ρ * wk.cp[i,j,k] * dx * dy * dz_k * ddt
wk.b[i,j,k] = -( a_p_0 * wk.θ[i,j,k] + wk.b[i,j,k] )
```
→ **符号反転あり**: `b = -(a_p_0 * θ + source)`

**Python版** (1272-1277行):
```python
rhs = a_p_0 * lambda_initial[i, j, k_ijk]

if k_ijk == 0:
    residual_scale = 0.5
    rhs += 2 * residual_scale * (T_cal[i, j] - Y_obs[i, j]) * dx * dy

b[p] = rhs
```
→ **符号反転なし**: `b = a_p_0 * λ + source`

**疑問点**:
1. 離散化の過程が違うため、単純に符号を反転すべきか不明
2. 元の連続方程式から離散化を追う必要がある
3. **符号の違いが10^11倍の差を生む可能性が高い**

---

### 🟡 要確認: 随伴方程式の定義

**Julia版コメント** (AdjointSolver.jl:6-7):
```julia
随伴方程式による感度解析（後退時間積分）：
    (I - α∇²)λ^(n-1) = λ^n + 2·(T_cal - Y_obs)
    α = (k·dt) / (ρ·cp·dx²)
```

**展開すると**:
```
(I - α∇²)λ^(n-1) - λ^n = 2·(T_cal - Y_obs)
```

**左辺を有限体積法で離散化**:
```
a_p·λ^(n-1) - (拡散項) - a_p_0·λ^n = source
```

**移項すると**:
```
a_p·λ^(n-1) - (拡散項) = a_p_0·λ^n + source
```

**さらに移項**:
```
(a_p - 拡散項)·λ^(n-1) = a_p_0·λ^n + source
```

**問題**: Python版とJulia版でどちらの形を使っているか不明確

## 📊 既知の事実

### ✅ 確認済み（一致）
1. **ソース項の位置**: k=0（底面）で残差注入
2. **ソース項の形式**: `2 * residual_scale * (T_cal - Y_obs) * dx * dy`

6. **比熱・熱伝導率**: 温度の関数（多項式）

2. **係数行列構造**: 要素レベルでの一致確認が必要
3. **境界条件**: 側面・上面の扱いが完全一致しているか
