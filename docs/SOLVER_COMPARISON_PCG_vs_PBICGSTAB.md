**収束パターン**:

- 安定期（t=3-13）: 4-5反復
- 後期（t=14-20）: 5-6反復（徐々に増加）

**長所**:
- 対称行列に対して効率的
- 実装がシンプル
- メモリ使用量が少ない

**短所**:
- 非対称行列（対流項含む）では収束が遅い
- 初期推定値の影響を受けやすい
- 反復回数の変動が大きい

**残差のスケーリング**:
- h=10: 残差 ~ 5×10⁻⁴
- h=100: 残差 ~ 5×10⁻³（10倍）

**収束性のh値独立性**:
- ✅ **両ソルバーとも反復回数はh値に依存しない**
- ✅ **適切な前処理とスケーリング**
- ✅ **実用的なh値範囲で安定動作**

## 🎯 技術的洞察

### なぜPBICGSTABが優れているのか？

#### 1. **非対称行列への最適化**
対流境界条件により係数行列は非対称性を持つ：
```
A·T = b, where A is non-symmetric due to:
- 対流項: h·A·(T - T_∞)
- ステンシル: 対角項に対流項が加わる
```

BiCGSTAB法は非対称行列に対して設計されており、効率的に収束する。

#### 2. **安定化手法**
BiCGSTABの「Stabilized」部分が重要：
- 残差の振動を抑制
- より滑らかな収束
- 数値的安定性の向上

#### 3. **前処理効果**
Gauss-Seidel前処理が対流項に効果的：
- 対角優位性の改善
- 条件数の低減
- より速い収束

#### 4. **体積積分形式との相性**
体積積分形式の対流境界条件：
```
対角項: (h·A + λ/dx + ... + a_p_0) * θ
隣接項: -λ/dx * θ_adjacent (対流項は含まない)
RHS項: -h·A·T_∞
```

この形式はBiCGSTAB法の収束特性に適している。

### なぜPCGが遅いのか？

#### 1. **対称性の仮定**
Conjugate Gradient法は対称行列を仮定：
```
A^T = A (対称性)
```

対流項により非対称性が増すと、この仮定が崩れて収束が遅くなる。

#### 2. **探索方向の非最適性**
非対称行列では共役方向が最適ではない：
- 探索方向が最小残差方向からずれる
- より多くの反復が必要

#### 3. **初期推定値の影響**
PCGは初期推定値の影響を受けやすい：
- t=2で6反復（線形外挿が効かない）
- t=16-20で5-6反復（時間発展により推定精度が低下）

## 🚀 推奨事項

### **推奨ソルバー: PBICGSTAB**

**採用理由**:
1. ✅ **反復回数が半分以下**（2反復 vs 4.7反復）
2. ✅ **極めて安定**（全ステップで2反復）
3. ✅ **h値によらず高性能**（スケーラビリティ抜群）
4. ✅ **予測可能**（常に2反復なので性能予測が容易）
5. ✅ **実装済み**（既存コードで完璧に動作）

**適用範囲**:
- 対流境界条件を含む全ての熱伝導問題
- h値が広範囲（1-10000 W/m²·K）の問題
- 大規模格子（80×100×20以上）の問題

### PCGの位置づけ

**使用を検討する場合**:
- 対称行列のみの問題（純粋な拡散問題）
- メモリが極端に制約される環境
- 実装の簡潔性が重要な場合

**推奨しない場合**:
- ❌ 対流境界条件を含む問題
- ❌ 非対称性の強い問題
- ❌ 高速収束が必要な場合
