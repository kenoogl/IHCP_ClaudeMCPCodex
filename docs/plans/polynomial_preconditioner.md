Polynomial (Neumann/Least-Squares) 近似前処理
============================================

概要
----
- 多項式前処理は `M^{-1} ≈ p_m(A)` の形で逆作用を近似し、行列‐ベクトル積 (`Ax`) とスカラー演算だけで前処理を適用する。明示的な疎行列格納が不要なため matrix-free 実装や高並列環境と相性が良い。
- 代表的なのは Neumann (Taylor) 展開と、残差最小化で係数を求める Least-Squares (最小二乗) 多項式。どちらも低次数で BiCGSTAB の収束を大きく改善できる。

Neumann (Taylor) 近似
--------------------
1. `A = D - R` に分解して `D` を解きやすい近似（対角やラインブロックなど）にとる。  
   `M = D^{-1}A = I - D^{-1}R` のスペクトル半径 ρ が 1 未満なら  
   `A^{-1} ≈ D^{-1} ∑_{k=0}^{m-1} (I - D^{-1}A)^k` が得られる。
2. 実装では `z = D^{-1} r` を初期化し、`e = z` を数回更新して合計するだけ。必要なのは `Ax` と `D^{-1}` の適用のみで、`D` が対角なら要素ごとの割り算になる。
3. ρ が 1 に近いと効果が落ちるため、Jacobi / ラインブロックなどで事前にスケーリングし `D^{-1}A` の固有値半径を抑えることが重要。

Least-Squares 多項式
-------------------
- `p_m` を `||I - p_m(A) A||` が最小になるよう決めるアプローチ。Chebyshev 近似に似ているが、Frobenius ノルムやサンプルベクトル上の残差最小化を直接目的にできる。
- 実装手順の一例:
  1. 複数のランダムベクトル `u_j` を用意し、`A` の少数回作用で Krylov 基底 `K_m(A, u_j)` を作る。
  2. 各基底で小規模最小二乗問題 `H c ≈ e` を解いて多項式係数 `c` を得る。
  3. 適用時は Horner 法で `z = p_m(A) r` を評価すれば良い。必要な作業ベクトルは数本。
- Neumann 近似より係数調整の自由度が高く、スペクトル推定が荒くても安定しやすい。

実装のポイント
--------------
- `Ax` が中心なので GPU / マルチスレッドに乗せやすい。Neumann 系の `D^{-1}` も独立要素ごとの計算で並列化しやすい。
- 固有値範囲はパワー法や Lanczos を数回回して推定（行列を持たなくても matvec だけで可能）。
- 打ち切り次数 `m` は 2～5 程度が実用的。次数を上げすぎると浮動小数誤差とコストが増える。
- 事前スケーリング（Jacobi / ブロックJacobi）で収束性が大きく変わるため、まずスケーリング→多項式前処理という流れが推奨。

BiCGSTAB への組み込み例
----------------------
- 既存の前処理呼び出し `Preconditioner!(z, r)` を差し替え、内部で多項式の Horner 展開を実装するだけで済む。
- `Ax` と `D^{-1}` が matrix-free のまま実装できれば、BiCGSTAB の各サイクルでも完全に並列化可能。
- 実測の残差履歴で効果を評価し、必要なら `m` やスケーリング手法 (`D` の選択) を調整する。

メリットと注意点
----------------
- 長所: matrix-free・メモリ一定・高並列化が容易・実装が軽量。
- 短所: 係数調整が必要、スペクトルが広い場合は効果が限定的。Neumann 系はスケーリングが不足すると発散するケースがある。
- すすめ方: Jacobi/ブロックJacobiで安定化 → パワー法で固有値推定 → Neumann (m≈3) または最小二乗 (m≈4) を構築し、BiCGSTAB の反復数/残差で評価。
