## 💡 なぜこれほど劇的に改善したのか？

### 1. 行列の条件数改善（主要因）

**体積積分形式の特徴**:
```julia
# 熱伝導項: 面積 × コンダクタンス形式
cond_xm = λf(...) * dy0 * dz_k * ddx

# 時間項: 体積積分形式
a_p_0 = ρ * cp[i,j,k] * dx0 * dy0 * dz_k * ddt

# 対角項: 熱伝導項 + 対流項 + 時間項（全て体積スケール）
dd = (oneT-m0) + (cond_xp + cond_xm + cond_yp + cond_ym + cond_zp + cond_zm +
                  conv_xp + conv_xm + conv_yp + conv_ym + conv_zp + conv_zm + a_p_0)*m0
```

**Phase 1-E（適応的収束判定）との違い**:
- Phase 1-E: 収束判定を緩和（tol=1e-6 → 1e-5）して反復回数削減
- 体積積分形式: **行列自体の条件数を改善**して収束性を根本的に向上

**理論的背景**:
1. **スケーリングの統一**: 全ての項が体積スケール（dx×dy×dz）で統一
   - 対角優位性が向上（対角項 >> 非対角項）
   - 前処理（Gauss-Seidel）の効果が最大化
2. **時間項の寄与**: `ρ * cp * dx * dy * dz / dt` が対角項を強化
   - 時間ステップdt=1msで、時間項が支配的（物理的に妥当）
   - 対角優位性が更に向上 → 収束が劇的に加速
3. **非対角項の抑制**: 隣接項は熱伝導項のみ（対流項を除外）
   - 対角項/非対角項の比が大幅に改善
   - 前処理の効果が倍増

### 2. 数値的安定性の向上

**Phase 1-Eの問題点**:
- 適応的tolの調整が一律（kappa_theta=0.2固定）
- ステップごとに反復回数がばらつく（t=5で540回、t=9で279回）
- 一部ステップで悪化（DHCP: t=5, t=7で反復回数増加）

**体積積分形式の利点**:
- 全ステップで安定した収束（DHCP: 11-12回で統一）
- 前処理の効果が均一に発揮
- tolの調整が不要（デフォルト1e-6で十分高速）

### 3. 前処理（Gauss-Seidel）との相乗効果

**Gauss-Seidel法の特性**:
- 対角優位行列で収束が速い
- 行列の条件数が良好なほど効果的

**体積積分形式の恩恵**:
- 対角項が強化 → GS法の収束性が最大化
- 5回のGS反復で十分な前処理効果
- 結果: PBICGSTAB本体の反復回数が10-12回に激減

## 🔍 技術的詳細

### 実装の核心部分

**CommonSolver.jl: lines 340-368（CalcRK!関数）**
```julia
# 熱伝導項（面積×コンダクタンス）
cond_xm = λf(λ[i-1,j,k], λ0, m[i-1,j,k], m0) * dy0 * dz_k * ddx
cond_xp = λf(λ[i+1,j,k], λ0, m[i+1,j,k], m0) * dy0 * dz_k * ddx
cond_ym = λf(λ[i,j-1,k], λ0, m[i,j-1,k], m0) * dx0 * dz_k * ddy
cond_yp = λf(λ[i,j+1,k], λ0, m[i,j+1,k], m0) * dx0 * dz_k * ddy
cond_zm = λf(λ[i,j,k-1], λ0, m[i,j,k-1], m0) * dx0 * dy0 / (ZC[k]-ZC[k-1])
cond_zp = λf(λ[i,j,k+1], λ0, m[i,j,k+1], m0) * dx0 * dy0 / (ZC[k+1]-ZC[k])

# 対流項（対角項のみに追加）
conv_xm = HC[1] * dy0 * dz_k * (oneT - m[i-1,j,k])
conv_xp = HC[2] * dy0 * dz_k * (oneT - m[i+1,j,k])
conv_ym = HC[3] * dx0 * dz_k * (oneT - m[i,j-1,k])
conv_yp = HC[4] * dx0 * dz_k * (oneT - m[i,j+1,k])
conv_zm = HC[5] * dx0 * dy0 * (oneT - m[i,j,k-1])
conv_zp = HC[6] * dx0 * dy0 * (oneT - m[i,j,k+1])

# 時間項（体積積分形式）
a_p_0 = ρ * cp[i,j,k] * dx0 * dy0 * dz_k * ddt

# 対角項: 熱伝導項 + 対流項 + 時間項
dd = (oneT-m0) + (cond_xp + cond_xm + cond_yp + cond_ym + cond_zp + cond_zm +
                  conv_xp + conv_xm + conv_yp + conv_ym + conv_zp + conv_zm + a_p_0)*m0

# 隣接項: 熱伝導項のみ（対流項は除外）
ss = ( cond_xp * θ[i+1,j  ,k  ] + cond_xm * θ[i-1,j  ,k  ]
     + cond_yp * θ[i  ,j+1,k  ] + cond_ym * θ[i  ,j-1,k  ]
     + cond_zp * θ[i  ,j  ,k+1] + cond_zm * θ[i  ,j  ,k-1] )
```

# 体積積分形式では、対流項 h·A·(θ - T∞) を以下のように分離:

### Z方向格子生成の修正

**問題**: Phase 1-Eでは大規模格子で無限ループが発生

**原因**: `run_10steps_fullsize_test.jl`の`build_z_grid()`関数で、底面・表面物理セルを境界値に設定 → ゼロ除算 → Inf/NaN → PBICGSTAB収束不能

**修正内容**（c2cff55コミット）:
```julia
# 修正前（問題あり）
z_centers[2] = z_faces[1]        # 0.0 → ゼロ除算
z_centers[nk+1] = z_faces[nk+1]  # Lz → ゼロ除算
if nk > 2
  for k in 3:nk
    z_centers[k] = (z_faces[k-1] + z_faces[k]) * 0.5
  end
end

# 修正後（統一）
for k in 2:nk+1
  z_centers[k] = (z_faces[k-1] + z_faces[k]) * 0.5
end
```

**結果**: 大規模格子（80×100×20）でも正常動作し、29.6秒で完了 ✅
