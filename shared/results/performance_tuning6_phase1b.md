## 詳細分析

### 1. DHCP外挿法（✅ 有効）

#### 線形外挿（-10.5%、111秒削減）

**CG反復数の変化**:
```
ベースライン → 線形外挿
DHCP:        5,043 → 4,910 (-2.6%)
Adjoint:     6,436 → 5,270 (-18.1%)
Sensitivity: 4,773 → 4,339 (-9.1%)
```

**時間ステップ別の効果**（DHCP）:
- t=2: 397反復（同じ、履歴不足）
- t=3: 583 → **316反復（-46%）** ✨
- t=4: 736 → 466反復（-37%）
- t=7: 483 → 1,038反復（+115%）⚠️ 一部で増加

**考察**: 線形外挿は全体的に有効だが、時間ステップにより効果にばらつき。

#### 二次外挿（-11.6%、123秒削減）

**CG反復数の変化**:
```
ベースライン → 二次外挿
DHCP:        5,043 → 3,997 (-20.7%) ✨
Adjoint:     6,436 → 5,424 (-15.7%)
Sensitivity: 4,773 → 4,891 (+2.5%)
```

**DHCP時間ステップ別**:
- t=2: 397反復（同じ）
- t=3: 583 → 316反復（線形と同じ）
- t=4: 736 → **326反復（-56%）** ✨ 線形より大幅改善
- t=5-10: 順調に削減

**結論**: **二次外挿が最も効果的**（11.6%改善）

#### なぜDHCP外挿が有効か

**理論的根拠**:
```
時間方向の温度場変化: T(t) ≈ a₀ + a₁·t + a₂·t²
→ 高次外挿で良好な初期推定
```

**実測データ**:
- 温度場の時間変化: 滑らか（550-588K、約38K変化）
- 外挿誤差: 実際の解に近い
- 反復削減: 特にt≥4で顕著

### 2. Adjoint残差戦略（❌ 無効、+1.1%悪化）

#### 期待と現実のギャップ

**期待**: 変分原理に基づく理論的に妥当な初期値
**現実**: 局所的改善は顕著だが、総合的には悪化

#### CG反復数の詳細

**時間ステップ別の変化**:
```
ステップ  :previous  :residual  変化率
t=9       1,348      275        -79.6% ✨ 劇的
t=8       653        2,237      +243%  ❌ 大幅増加
t=7       586        991        +69%   ❌
t=6       650        561        -14%   ✓
t=5以前   ~650       ~620       微減   ✓

総合      6,436      6,804      +5.7%  ❌
```

#### なぜt=9で劇的改善？

**理論的説明**:

随伴方程式の最終時刻境界条件:
```
λ(t_final) = ∂J/∂T = 2(T_cal - Y_obs)
```

残差戦略はこの境界条件を初期値として使用:
```
λ[:,:,1,t=9] = Y_obs - T_cal  # 残差を直接配置
```

→ 真の解に非常に近い初期推定 → 275反復（-79.6%）

#### なぜt=8で大幅悪化？

**数値的問題**:

1. **初期残差の増大**:
   ```
   t=9: Res_0 = 3.76×10⁷  ← 残差初期値により大きな値
   t=8: 反復解法が収束に苦労 → 2,237反復必要
   ```

2. **時間方向への伝播**:
   - t=9の解（残差初期値由来）を初期値として使用
   - 残差初期値の影響が時間方向に伝播
   - 収束特性が悪化

#### 理論 vs 実践

**理論的妥当性**: ✅ 変分原理から導出、数学的に正しい
**実用的効果**: ❌ 反復解法との相性で総合的には悪化

**教訓**: 理論的に正しい ≠ 数値的に最適

### 3. Sensitivity外挿法（❌ 無効、4-7%悪化）

#### CG反復数の変化

**線形外挿（+7.3%、77秒増加）**:
```
ベースライン → 線形外挿
DHCP:        5,043 → 5,043 (同じ、固定)
Adjoint:     6,436 → 6,436 (同じ、固定)
Sensitivity: 4,773 → 6,058 (+27%) ❌
```

**二次外挿（+4.3%、45秒増加）**:
```
Sensitivity: 4,773 → 5,548 (+16%) ❌
```

#### なぜSensitivity外挿が無効か

**Sensitivity問題の特性**:
```
∂T/∂t - ∇·(k∇(∂T/∂q)) = 境界条件: ∂q（探索方向）
```

1. **問題の性質**:
   - 温度の微分（感度）を計算
   - DHCPより変化が急峻
   - 外挿の仮定（滑らかな変化）が成立しにくい

2. **実測データ**:
   - t=7で反復数が2倍以上に増加
   - 外挿による初期推定が実際の解から乖離

**結論**: Sensitivity問題では外挿は逆効果

## 学んだ教訓

### 1. 理論的妥当性 ≠ 実用的効果

Adjoint残差戦略は変分原理から導出された理論的に正しいアプローチだが、反復解法との相性で実用的効果が得られなかった。

**教訓**: 数値解析では理論と実装の橋渡しが重要。

### 2. 問題の特性理解が鍵

DHCP外挿は有効だが、Sensitivity外挿は無効。これは各問題の時間変化特性の違いに起因。

**教訓**: 一律のアプローチではなく、問題ごとの特性を考慮。

### 3. 実験的検証の重要性

理論的に有望なアプローチでも、実際にベンチマークを実行するまで効果は不明。

**教訓**: 仮説→実装→検証のサイクルを回す。
