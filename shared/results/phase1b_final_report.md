## 🔍 詳細分析

### 1. DHCP外挿効果

**線形外挿** (シナリオ2):
- 改善率: -10.5%
- 特徴: 初期ステップでの収束が高速化
- CG反復削減: 5,043 → 4,910回 (-2.6%)

**二次外挿** (シナリオ3):
- 改善率: -11.6%
- 特徴: 線形外挿よりさらに高精度な初期推定
- CG反復削減: 5,043 → 3,997回 (-20.7%)
- **結論**: **二次外挿が最適** ✅

### 2. Adjoint残差戦略（シナリオ4）

- 改善率: +1.1%（**悪化**）
- 原因: 残差ベースの初期値が不適切
- Adjoint solver時間: 446.0s → 464.7s (+4.2%)
- **結論**: **不採用** ❌

### 3. Sensitivity外挿効果（シナリオ5, 6）

- 線形外挿: +7.3%（悪化）
- 二次外挿: +4.3%（悪化）
- 原因: Sensitivity方程式の特性上、外挿が逆効果
- **結論**: **不採用** ❌

### 4. Adjoint残差スケール係数（シナリオ7, 8, 9）

**0.5倍スケール** (シナリオ7):
- 改善率: **-16.3%**（最良）
- Sensitivity solver: 300.0s → **257.4s** (-14.2%)
- 総合効果: DHCP二次外挿との相乗効果

**0.2倍スケール** (シナリオ8):
- 改善率: -13.1%（中程度）
- Sensitivity solver: 300.0s → 283.7s (-5.4%)

**0.1倍スケール** (シナリオ9):
- 改善率: -11.6%（DHCP二次のみと同等）
- Sensitivity solver: 300.0s → 299.0s (-0.3%)
- スケールが小さすぎて効果薄

**結論**: **0.5倍が最適** ✅

## 🔬 技術的洞察

### 1. DHCP二次外挿が有効な理由

- 温度場の時間変化が2次関数的
- 3点（t-2, t-1, t）からの外挿で高精度な初期推定
- 初期ステップでのCG反復を大幅削減

### 2. Adjoint残差スケールの効果

- Adjoint方程式の残差を0.5倍にスケーリング
- Sensitivity方程式の右辺項が適度に縮小
- CG収束が加速（過度な縮小は逆効果）

### 3. 相乗効果のメカニズム

1. DHCP二次外挿 → DHCP solverの高速化
2. 高精度なDHCP解 → Adjoint solverの収束改善
3. Adjoint残差0.5倍 → Sensitivity solverの高速化
4. **総合的な性能向上** → -16.3%改善
