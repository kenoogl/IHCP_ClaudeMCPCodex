### 最適化のコア実装

#### tensor_dot最適化

```julia
# 変更前
function tensor_dot(a::Array{T}, b::Array{T}) where T <: Real
  return Float64(dot(vec(a), vec(b)))  # vec()でコピー発生
end

# 変更後
function tensor_dot(a::AbstractArray{T1}, b::AbstractArray{T2}) where {T1 <: Real, T2 <: Real}
  acc = zero(promote_type(T1, T2))
  @inbounds @simd for idx in eachindex(a, b)
    acc += a[idx] * b[idx]  # コピーなし、SIMD最適化
  end
  return Float64(acc)
end
```

**効果**: `vec()`による一時配列生成を回避、`@simd`によるベクトル化

#### バッファ再利用パターン

```julia
# CGMループ外で事前確保
dhcp_T_buffer = zeros(Float64, ni, nj, nk, nt)
dhcp_iter_buffer = zeros(Int, nt)

# ループ内で再利用

    dx, dy, Z, ΔZ, dt;
    T_buffer=dhcp_T_buffer,      # 再利用
    iter_buffer=dhcp_iter_buffer  # 再利用
  )
end
```

**効果**: CGM反復ごとのアロケーションを1回のみに削減
