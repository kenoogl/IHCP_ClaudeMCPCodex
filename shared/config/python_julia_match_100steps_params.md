# Python-Julia 計算結果一致確認パラメータ仕様（100ステップ版）

## 概要
このドキュメントは、Python版とJulia版の逆熱伝導問題（IHCP）ソルバーの計算結果一致検証用パラメータを定義します。
両実装で完全に同一のパラメータを使用し、数値計算結果の一致を確認します。

**改訂版の特徴:**
- **ステップ数**: 300 → 100に削減（計算時間短縮）
- **CGM反復数**: 2 → 1に削減（既存検証と同じ条件）
- **目的**: 高速な動作確認と一致性検証

## データファイル
- **入力データ**: `shared/data/T_measure_700um_1ms.npy`
  - 形状: (nt, ni, nj) = (100, 80, 100) ※100ステップに制限
  - データ型: float64
  - IRカメラ測定温度データ（表面温度）

- **熱物性値**: `shared/data/metal_thermal_properties.csv`

## 検証基準

### 一致判定基準
1. **熱流束相対誤差**: max|q_python - q_julia| / max|q_python| < 0.01% (0.0001)
2. **温度場相対誤差**: max|T_python - T_julia| / max|T_python| < 0.01% (0.0001)
3. **絶対誤差**: max|q_python - q_julia| < 1.0 W/m² (熱流束)
4. **絶対誤差**: max|T_python - T_julia| < 0.01 K (温度)

### 既知の差異
- **なし**: 両実装は完全に同一のアルゴリズムを使用し、ビット単位の一致を目指します

## 実装上の注意事項

### 配列インデックス
- **Python**: 0-indexed, 形状順序 (nt, ni, nj) または (nt, ni, nj, nk)
- **Julia**: 1-indexed, 形状順序 (ni, nj, nt) または (ni, nj, nk, nt)

### データ型
- すべての浮動小数点演算を **float64** で統一

### 乱数シード
- 使用しない（決定論的計算のみ）

### ファイルI/O
- NPZ形式を使用（NumPy/NPZ.jl互換）
- 圧縮なしで保存（ビット単位の一致確認のため）

## 参考情報

### 既存の検証結果（357ステップ版、CGM反復1回）
- Python計算時間: 92.46秒
- Julia計算時間: 1179.03秒
- 速度比（Julia/Python）: 12.8倍遅い
- 熱流束相対誤差: 最大 0.0041%
- 温度場相対誤差: 最大 0.0047%

### 推定計算時間（100ステップ版、CGM反復1回）
- **Python版**: 約25-35秒（Numba 8スレッド）
- **Julia版**: 約330-440秒（5.5-7.3分、逐次実行）

**計算根拠:**
- 357ステップ → 100ステップ: 約28%に削減
- ウィンドウ数: 約24 → 2に削減（1/12）
- Python: 92.46秒 × (100/357) = 約26秒
- Julia: 1179.03秒 × (100/357) = 約330秒
